## Scope

This course is taught to second-year students who major in computer science.
Its goal is to provide a working understanding of how hardware and operating systems behave under the hood,
so that software performance, execution models, memory behaviour, and system interfaces stop feeling opaque.

## Structure

The course is split into two connected parts.
The first part is given in **module 3** and covers computer architecture and assembly language programming,
with a focus on the [RISC-V](https://en.wikipedia.org/wiki/RISC-V) instruction set architecture.
The second part is given in **module 4** and covers operating system organisation and system programming
with [Linux](https://en.wikipedia.org/wiki/Linux) and the [C programming language](https://en.wikipedia.org/wiki/C_%28programming_language%29).
