  19. BinarySearch

    Write a function binsearch.s that accepts pointer to sorted array (a0), value to find (a1), start and end indices of search (a2 and a3). The function returns (a0) index in the same way as the C code below. The array is sorted. It is created manually and placed in the static data memory (the .data section). To find the value in the array, the binary search algorithm is used. It must be implemented as a recursive function, which in the C programming language looks like this:

    int binary_search(int *data, int value, int start, int end)
{
    int mid = start + (end - start) / 2;
    if (start > end)
        return -1;
    if (data[mid] == value)
        return mid;
    if (data[mid] > value)
        return binary_search(data, value, start, mid - 1);
    return binary_search(data, value, mid + 1, end);
}
