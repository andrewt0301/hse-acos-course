## Формула оценки

__Grade = 0.4 * Теория + 0.6 * Задача__

## Дедлайн

* __Время начала: 16:00__
* __Время окончания: 17:30__

## Правила

Разрешается использовать RARS, калькулятор, текстовый редактор для заметок,
консоль Linux. Политика по борьбе с плагиатом описана [здесь](../grades.md#cheating-policy).

## Прокторинг

Запишите видео при помощи [OBS Studio](https://obsproject.com),
загрузить его в облако и пришите ссылку. Видео должно включать экран, камеру и звук. Рекомендуемый формат видео `.mkv` (должно получить относительно небольшим).

На видео должны быть обе части (теория и программа). Включить запись перед тем, как приступить к решению.

Видео: Ссылку на видео отправить в эту [форму](https://forms.gle/7qCS1QXeqMgTZgHdA).
Форма для видео будет доступна после дедлайна на случай, если загрузка будет занимать длительное время.

## Часть 2: Задача по программированию

Написать на ассемблере RISC-V программу, которая реализует функцию `f(x)`
согласно заданной формуле. У каждого студента свой индивидуальный вариант формулы.
Задание разбито на 7 задач (шагов). Это сделано для того, чтобы можно было оценить неполные решения.

Критерии оценивания:

1. Полное решение задач 1-4 даёт по 1 баллу за каждую задачу.
2. Полное решение задач 5-7 даёт по 2 балла за каждую задачу.
3. Полное решение всех задач дает в сумме 10 баллов.

Замечания:
1. Не используйте какие-либо Web Proxy.
