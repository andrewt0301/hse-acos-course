Scope

This course is taught to second-year students who major in computer science. Its goal is to provide a working understanding of how hardware and operating systems behave under the hood, so that software performance, execution models, memory behaviour, and system interfaces stop feeling opaque.

Structure

The course is split into two connected parts. The first part is given in module 3 and covers computer architecture and assembly language programming, with a focus on the RISC-V instruction set architecture. The second part is given in module 4 and covers operating system organisation and system programming with Linux and the C programming language.

This Site

This repository hosts lecture materials, workshop references, homework and final-test pages, software setup instructions, grading rules, and supporting resources connected to the course. For information on course administration such as deadlines and university procedures, please refer to the official university pages.

M03

Module 3

Computer Architecture

RISC-V, processor design, memory hierarchy, virtual memory, parallelism, and optimization.

Lecture sequence

  1. Introduction. Course motivation. Historical perspective.
  2. Data types. Byte ordering. Integer formats.
  3. Computer organization. Microprocessor. RISC and RISC-V. Assembly language.
  4. RISC-V instructions. Instruction formats.
  5. Pseudo instructions, macros, and includes. Conditions, loops, loads, and stores.
  6. Subroutines. Call stack. Calling conventions.
  7. Floating-point format. IEEE 754. Floating-point instructions.
  8. Memory and caches.
  9. Virtual memory.
  10. Processor and pipeline.
  11. Exceptions and interrupts.
  12. Input and output.
  13. Instruction-level parallelism: Multiple issue and out-of-order execution.
  14. Thread-level parallelism.
  15. Optimizations.
  16. Data-level parallelism: Vectors and SIMD.
Homeworks Final test
M04

Module 4

Operating Systems

Linux internals, C, processes, files, networking, linking, and system programming.

Lecture sequence

  1. Operating system architecture. Linux.
  2. C programming language.
  3. System calls.
  4. Executable file format. Linking and loading.
  5. Dynamic memory allocation and string handling.
  6. Processes and threads.
  7. I/O and files.
  8. Synchronization.
  9. Inter-process communication.
  10. Users, groups, and permissions.
  11. Virtual Machines.
  12. Networking.
  13. Sockets.
  14. High-level Languages and Operating System.
