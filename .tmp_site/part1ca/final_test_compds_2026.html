Контрольная Работа: Архитектура Компьютера

Формула оценки

Grade = 0.4 * Теория + 0.6 * Задача

Дедлайн

  • Время начала: 13:00
  • Время окончания: 14:30

Правила

Разрешается использовать RARS, калькулятор, текстовый редактор для заметок, консоль Linux. Политика по борьбе с плагиатом описана здесь.

Прокторинг

Запишите видео своего экрана при помощи OBS Studio, закгрущить его в облано и пришите ссылку. Рекомендуемый формат видео .mkv (должно получить относительно небольшим).

На видео должны быть обе части (теория и программа). Включить запись перед тем, как приступить к решению.

Видео: Ссылку на видео отправить в эту форму.

Часть 1: Теория

Ответьте на вопросы по теории в этой форме.

Часть 2: Задача по программированию

Написать на ассемблере RISC-V программу, которая реализует функцию f(x) согласно заданной формуле. У каждого студента свой индивидуальный вариант формулы. Задание разбито на 7 задач (шагов). Это сделано для того, чтобы можно было оценить неполные решения.

Критерии оценивания:

  1. Полное решение задач 1-4 дает по 1 баллу за каждую задачу.
  2. Полное решение задач 5-7 дает по 2 балла за каждую задачу.
  3. Полное решение всех задач дает в сумме 10 баллов.

Замечания:

  1. Не используйте Web Proxy.
