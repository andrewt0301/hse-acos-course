Java Virtual Machine and Bytecode

Installing Java:

sudo apt install openjdk-21-jdk

Simple program Hello.java:

public class Hello {
  public static void main(String[] args) {
    int x = 10;
    int y = 20;
    int z = (x + y) / (y - x);
    System.out.printf("z=%d\n", z);
  }
}

Compiling the program and viewing its bytecode:

javac Hello.java 
javap -c Hello
